Welcome to project Axiom!

Project Axiom is a web component set which aims to combine good part of Fluent Design System and Material Design to a single design language.

This repo contains code of Navigation Indicator animation of Fluent design System.

Default Item

To change the default item, just simply add a default attribute to navigation item.

<ax-navigation>
    <ax-navigation-item>Home</ax-navigation-item>
    <ax-navigation-item default>Apps</ax-navigation-item>
    <ax-navigation-item>Games</ax-navigation-item>
  </ax-navigation>

Switch Event

A `switch` event will be dispatched if you switched from one tab to another tab.

document.querySelector('.switch-event').addEventListener('switch', (event) => {
  document.querySelector('.switch-information').innerHTML = `You've switched from ${event.detail.from.innerText} to ${event.detail.to.innerText}`
});

Shapes

The indicator is a shape of @ax-design/surface and takes its properties. The shape is drawn into the bar the current item occupies: --navigation-indicator-width across the bar, the width of the item along it. Without any of these properties the indicator is a plain rectangle. In the names below, {corner} is one of top-left, top-right, bottom-right, bottom-left and {side} is one of top, right, bottom, left.

Animated Indicator

The element carries moving, forward or backward, while the indicator runs, and the end features transition on it.

ax-navigation {
  --navigation-indicator-speed: 900ms;
  --navigation-indicator-width: 14px;
  --ax-edge-right-kind: triangle;
  --ax-edge-right-span: 100%;
  --ax-edge-left-kind: triangle;
  --ax-edge-left-span: 100%;
  transition: --ax-edge-right-depth 200ms, --ax-edge-left-depth 200ms;
}

ax-navigation[moving="forward"] {
  --ax-edge-right-depth: 9px;
  --ax-edge-left-depth: -7px;
}

ax-navigation[moving="backward"] {
  --ax-edge-left-depth: 9px;
  --ax-edge-right-depth: -7px;
}
