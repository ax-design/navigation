Welcome to project Axiom!

Project Axiom is a web component set which aims to combine good part of Fluent Design System and Material Design to a single design language.

This repo contains code of Navigation Indicator animation of Fluent design System.

Default Item

To change the default item, just simply add a default attribute to navigation item.

<ax-navigation>
    <ax-navigation-item>Home</ax-navigation-item>
    <ax-navigation-item default>Apps</ax-navigation-item>
    <ax-navigation-item>Games</ax-navigation-item>
  </ax-navigation>

Switch Event

A `switch` event will be dispatched if you switched from one tab to another tab.

document.querySelector('.switch-event').addEventListener('switch', (event) => {
  document.querySelector('.switch-information').innerHTML = `You've switched from ${event.detail.from.innerText} to ${event.detail.to.innerText}`
});

Shapes

The indicator is a shape of @ax-design/surface, so it takes that contract: corners move and change shape, and every side carries one feature. A navigation without any of these properties shows the plain rectangle it always did. The bar is --navigation-indicator-width across and the width of the current item along, and the same frame is used in both directions, so top and bottom are the two long sides (top facing the content) and right and left are the end it moves toward and the end it starts from.

Pill

A radius of half the thickness rounds both ends of the bar.

ax-navigation {
  --navigation-indicator-width: 14px;
  --ax-radius: 7px;
}

Cut corners

The corner shape of surface applies to the indicator: round, bevel, scoop or notch.

ax-navigation {
  --navigation-indicator-width: 14px;
  --ax-radius: 6px;
  --ax-corner-shape: bevel;
}

Scooped corners

A scoop bends the corner inward, so the bar gains a waist at both ends.

ax-navigation {
  --navigation-indicator-width: 14px;
  --ax-radius: 5px;
  --ax-corner-shape: scoop;
}

Notched corners

A notch cuts the corner out of the bar.

  --ax-radius: 6px;

Parallelogram

Moving two opposite corners on x leans the bar. The same declaration leans a vertical navigation too.

ax-navigation {
  --navigation-indicator-width: 14px;
  --ax-corner-top-left-shift-x: 10px;
  --ax-corner-bottom-right-shift-x: 10px;
}

A bump along the bar

An edge feature sits on one of the four sides. bottom is the long side away from the content.

ax-navigation {
  --navigation-indicator-width: 12px;
  --ax-radius: 6px;
  --ax-edge-bottom-kind: arc;
  --ax-edge-bottom-depth: 5px;
  --ax-edge-bottom-span: 40%;
}

A bite into the bar

A negative depth puts the arc into the bar instead of out of it.

ax-navigation {
  --navigation-indicator-width: 18px;
  --ax-radius: 9px;
  --ax-edge-top-kind: arc;
  --ax-edge-top-depth: -6px;
  --ax-edge-top-span: 34%;
}

A pointed end

right is the end the indicator moves toward, left the one it starts from. Their sides are the thickness of the bar, so a feature that spans all of it caps the end.

ax-navigation {
  --navigation-indicator-width: 14px;
  --ax-edge-right-kind: triangle;
  --ax-edge-right-depth: 8px;
  --ax-edge-right-span: 100%;
}

The same shape, both directions

The declaration written for the horizontal bar leans the vertical one the same way. Nothing is written twice and no direction-dependent property name appears.

ax-navigation {
  --ax-corner-top-left-shift-x: 10px;
  --ax-corner-bottom-right-shift-x: 10px;
